# SilkMark felhasználói dokumentáció

A SilkMark célprofilja: **CommonMark-szerű alap Markdown + gyakorlati GFM + dokumentáció-orientált natív kiterjesztések**.

A kézikönyv három szintre bontja a használható szintaxist:

1. [Alap, hordozható Markdown](standard-markdown.md) – ezt érdemes előnyben részesíteni általános dokumentumoknál.
2. [SilkMark-ajánlott kiterjesztések](recommended-extensions.md) – dokumentációhoz kifejezetten hasznos, stabil SilkMark/GFM funkciók.
3. [Kompatibilitási kiterjesztések](compatibility-extensions.md) – támogatott formák meglévő dokumentumokhoz, de új dokumentumban kevésbé ajánlottak.

> A SilkMark széles CommonMark/GFM-kompatibilitást céloz, de nem állítja, hogy a CommonMark specifikáció minden ritka edge case-ét bitre pontosan implementálja.
