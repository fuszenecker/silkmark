# SilkMark user documentation

SilkMark targets **CommonMark-like core Markdown + practical GFM + documentation-oriented native extensions**.

The guide separates syntax into three levels:

1. [Core portable Markdown](standard-markdown.md) – prefer this for generally portable documents.
2. [Recommended SilkMark extensions](recommended-extensions.md) – stable SilkMark/GFM features that are useful for technical documentation.
3. [Compatibility extensions](compatibility-extensions.md) – accepted for existing documents, but usually not preferred for new content.

> SilkMark aims for broad practical CommonMark/GFM compatibility, but does not claim bit-for-bit coverage of every rare CommonMark parser edge case.
