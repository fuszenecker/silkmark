# CommonMark standard additions

Indented code block:

    fn main() {
        println!("Hello");
    }

Parenthesized ordered marker:

1) first
2) second
3) third

URI autolink: <https://example.org/>

Email autolink: <user@example.com>

Raw HTML remains intentionally inert in SilkMark:

<div>This is displayed as literal text.</div>
